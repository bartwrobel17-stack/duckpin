# Duckpin Gniezno

A responsive restaurant and entertainment landing page built with Next.js, React, TypeScript and custom CSS.

## Run locally
```bash
npm install
npm run dev
```

## Build checks
```bash
npm run typecheck
npm run build
```

## Notes
- Business facts currently used: Duckpin, Dąbrówki 15/2, 62-200 Gniezno, phone 733 133 431, Google rating 4.7 based on 53 reviews, approximate spend 20–40 zł per person, dine-in and takeaway.
- Food names, food photography, and gallery images are illustrative placeholders. No actual menu prices or official restaurant photos were supplied. Replace the illustrative menu and images with owner-approved information before launch.
- Opening hours and social links were not supplied, so the site does not invent them.
- The contact section links to phone and a Google Maps search.
- No owner/admin dashboard or server authentication has been implemented yet. A production owner panel requires server-side authorization and a database/storage integration.
- Update `metadataBase` and sitemap URL if the final production domain is not `https://duckpin.pl`.
